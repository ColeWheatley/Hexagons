# snow_backend/snowpack — 1D snowpack engine + sidecar emission

FSM2-class multi-layer energy-balance snowpack over the L1 column registry
(473k columns beta), JAX (jit + scan), CPU or GPU from the same code.  Design
rationale: `snowpack_engine_design.md` (scratchpad / task #2).

- 5 snow layers + 2 soil layers, backward-Euler conduction with the surface
  flux linearized about the previous surface temperature, 2 fixed Newton
  outers, Thomas solve unrolled over 7 rows.  Empty layers are pass-through
  nodes, so bare ground and snowpack share one code path with zero branching.
- Canonical-profile relayering every step (targets 0.1/0.2/0.4/0.8/rest m,
  conservative overlap remap) — no merge/split control flow.
- Weak layers: 3-slot Lagrangian marker stack in SWE coordinates
  (facet-potential heuristic → burial push → sintering strength growth →
  destroyed when the melt front reaches them).  Slab depth = depth above the
  shallowest active marker.
- Mass audit closes to <0.01 mm over a full winter (unit-tested + printed by
  every backfill run).

## Run

```
pixi run python -m unittest discover snow_backend/snowpack/tests   # 8 tests
pixi run python snow_backend/snowpack/run_backfill.py --tiles all --days 181
pixi run python snow_backend/snowpack/station_compare.py
pixi run python snow_backend/snowpack/calibrate.py --check-grad
```

`--tiles station` runs the 9 tiles containing/nearest validation stations
(mini E2E, ~1 min CPU).  Sidecar bodies are always full `tile_count × 2401`;
un-simulated tiles are NODATA 0.

## Sidecar output contract (frontend consumer)

Path `<base>/<layer>/<YYYY>/<MM>/<DD>/<HH>.pfl`; body = `tileCount × 2401`
bytes, tiles in `tile_manifest.json tiles[]` order, depth-4 heap order within
tile; **byte 0 = NODATA everywhere, real domain 1..255**
(`value = (byte-1)/254 * (hi-lo) + lo` for `u8_linear`; byte = class index
for `u8_class`, `classes[0]` reserved).  A 32-byte `PFL1` header is always
written (the doc's "12 reserved" would make 36 B, but the consumer reads the
body from offset 32, so reserved is 8 — flagged upstream).  `manifestHash` =
CRC32 of the manifest tiles[] `(yq, yr)` `<i4` sequence.  `index.json` +
`latest.json` are generated by `sidecar.build_index` (coverage bitmask over
4,344 hourly slots from 2025-11-01T00Z; avalanche layer declared with
per-field aggregates: release or / severity max).

Display layers: `sqh` [0,100] mean, `depth` cm [0,500] mean, `surface`
classes `["—","powder","settled","wind slab","crust","wet","refrozen","bare"]`
mode.  (`avalanche` is emitted by the avalanche pipeline.)

## AVALANCHE-CONSUMER READ CONTRACT (state-summary layers)

Same .pfl format/paths, listed under `engine_layers` in index.json:

| layer | encoding | meaning |
|---|---|---|
| `slab`  | u8_linear cm [0,508] (2 cm quanta) | depth above shallowest **active weak-layer marker**; byte 1 = no active marker |
| `hn24`  | u8_linear mm w.e. [0,254] | 24 h new-snow water equivalent |
| `hn72`  | u8_linear mm w.e. [0,254] | 72 h new-snow water equivalent |
| `wet`   | u8_class `["—","dry","moist","wet","refrozen"]` | surface wetness state |
| `sdens` | u8_linear kg/m³ [0,1016] (4 kg/m³ quanta) | surface-layer density |

Harmonized avalanche byte (what the avalanche pipeline emits back): bit 7 =
release flag, bits 0–6 = severity, 0 = NODATA, 1 = simulated-none.

## SQH v1 (documented heuristic, calibratable)

`SQH = 100 · s_fresh · s_soft · s_dry · s_base` with
`s_fresh = 1 − exp(−HN72/30 mm)`, `s_soft = clip((250 − ρ_surf)/150)`,
`s_dry ∈ {1 dry, 0.5 moist, 0.15 wet, 0.1 refrozen}`,
`s_base = clip(HS/40 cm)`.  Zero when snow-free.

## Snapshots & restart

`run_backfill` writes `snow_backend/data/snapshots/state_dNNN.npz` every 7
days + at end: every state array + `meta` JSON (`next_hour_index`, full theta).
R2 upload is a deliberate non-goal of this module for now — sync the
`sidecars/` and `snapshots/` dirs with rclone/aws once the deploy bucket
layout is fixed (task #11).

## Calibration

`calibrate.py` implements the station-column shortcut: full-winter
`jax.value_and_grad` through `lax.scan` on just the station columns
(`--check-grad` smoke-tests one loss+gradient evaluation).  8 calibratable
scalars, multiplicative parameterization (`params.CALIBRATABLE`).
